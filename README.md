# 📊 OKX Order Book Collector  

Этот проект собирает **стаканы (order books)** с биржи **OKX** через **WebSocket** и предоставляет API для получения данных.  

---

## 🚀 Функционал  
✅ Подключение к WebSocket OKX и сбор стаканов    
✅ API `/orderbook/{instrument_id}` для получения стакана глубиной 400  
✅ Авто-переподключение при разрыве WebSocket  

---

## 🛠️ Установка  

### **1️⃣ Клонируй репозиторий**  
```bash
git clone https://github.com/ТВОЙ_ГИТ/okx-orderbook-collector.git
cd okx-orderbook-collector
```

### **2️⃣ Создай виртуальное окружение**
```bash
python -m venv .venv
source .venv/bin/activate  # Для macOS/Linux
```

### **3️⃣ Установи зависимости**
```bash
pip install -r requirements.txt
```

### **▶️ Запусти сервер**
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### **🔹 Как работает реконнект WebSocket?**
Сервис подключается к WebSocket OKX и подписывается на стаканы.
Если соединение разрывается, система автоматически:    
1) Ловит ошибку разрыва (ConnectionClosedError).    
2) Ждет 5 секунд перед повторным подключением.    
3) Создает новое WebSocket-соединение и повторно подписывается на стаканы.    
Если соединение разорвется снова, процесс повторяется бесконечно.   

Переподписка на стакан (resubscribe()) выполняется, если данные пришли с ошибкой.

### **🔹 Как хранится кэш стаканов?**
Система хранит данные в словаре (dict), где:    
Ключ — это ID инструмента (BTC-USDT).    
Значение — это объек с asks, bids и seqId.    

**Как обновляется кэш?**    
При получении snapshot (полный стакан) заменяем старые данные.    
При update (изменения стакана) обновляем только измененные уровни.
